# Apprendre les commandes linux en jouant
## Créer sa debian en VM
Paramétrée en NAT
Il faudra un profil utilisateur en plus du root

## Installer GameShell
- Aller sur https://github.com/phyver/GameShell/releases
  - Copier le lien gameshell.sh
    - Sur le ssh, ouvert avec le CMD
      - Commande : wget *coller_lien_gameshell*
    - Executer le fichier téléchargé (pas en profil root)
      - Commande : bash gameshell.sh
