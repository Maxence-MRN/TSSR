# Upload Automatique d'inventaire GLPI pour Windows
## Sur Windows Client
- Download la dernière version pour Windows : [Github Agent GLPI release latest](https://github.com/glpi-project/glpi-agent/releases/latest) 
*Nota : Pour un WinServ, le télécharger sur hostPC et copy/paste ensuite sur Serv.*
  - Lancer l'installation
    - Complète
      - Remote : https://*@IPGLPI*/glpi
      - Installer
      - Finish
  - Ouvrir page web
    - Url : http://127.0.0.1:62354
      - Force Inventory
## Retour sur GLPI Admin

- Contrôler si l'ajout à l'inventaire est bon.
  - Parc
    - Ordinateurs
