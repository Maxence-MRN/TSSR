# Séquence OS #

## Histoire OS ##

#### 1969 - Création d'Unix
Bell Labs développe **Unix**. Unix introduit des concepts encore utilisés aujourd'hui : système de fichiers hiérarchique, gestion des processus et philosophie de modularité.

#### 1977 - DOS
Création du Disk Operating System

#### 1981 - MS-DOS
Clone du DOS avec une upgrade par microsoft. Donnera Windows 1.0 en 1985.

#### 1983 - BSD (Berkeley Software Distribution)
Version d'Unix développée à Berkeley intégrant TCP/IP, technologie fondamentale de l'Internet moderne.

#### 1984 - Macintosh System 1
Découle de BSD, Apple commercialise le Macintosh avec une interface graphique (GUI) conviviale, popularisant l'utilisation de la souris et des fenêtres.

#### 1985 - Windows 1.0
Microsoft lance **Windows 1.0**, sa première interface graphique reposant sur MS-DOS. 

#### 1990 XENIX
Windows tente un OS sous UNIX. C'est un échec complet.

#### 1991 - GNU/Linux
Le noyau **Linux** est publié par Linus Torvalds. Il deviendra la base de nombreuses distributions open source ainsi que de la majorité des serveurs modernes.

#### 1993 - Windows NT
Windows NT 3.1 marque le début d'une nouvelle architecture pour Windows, plus stable et sécurisée que la branche MS-DOS. 

#### 1995 - Windows 95
Windows 95 démocratise l'informatique personnelle grâce au menu Démarrer et une interface moderne.

#### 2001 - Windows XP
Windows XP unifie les gammes grand public et professionnelles de Microsoft autour du noyau **Windows NT** (NTS5.1).

#### 2007 - Windows Vista
Un windows NT6, qui introduit le concept d'élévation de privilèges dans le cadre de la sécurité.

#### 2009 - Windows 7

La version la plus appréciée de l'histoire selon certains. Successeur de Vista, c'est la version du noyau NT6.1

#### 2007 - iPhone OS (iOS) ET Androïd
