#Cheat Sheet - Raccourcis Touche Windows

## Gestion du système

| Raccourci | Action |
|-----------|---------|
| `Win` | Ouvrir/Fermer le menu Démarrer |
| `Win + A` | Ouvrir les Paramètres rapides |
| `Win + I` | Ouvrir les Paramètres |
| `Win + X` | Ouvrir le menu administrateur |
| `Win + L` | Verrouiller la session |
| `Win + U` | Ouvrir les options d'accessibilité |
| `Win + Pause` | Afficher les informations système |

---

## Recherche et exécution

| Raccourci | Action |
|-----------|---------|
| `Win + S` | Rechercher |
| `Win + Q` | Rechercher |
| `Win + R` | Exécuter une commande |
| `Win + E` | Ouvrir l'Explorateur de fichiers |

---

## Gestion des fenêtres

| Raccourci | Action |
|-----------|---------|
| `Win + D` | Afficher/Masquer le Bureau |
| `Win + M` | Réduire toutes les fenêtres |
| `Win + Shift + M` | Restaurer les fenêtres réduites |
| `Win + ↑` | Agrandir la fenêtre |
| `Win + ↓` | Restaurer ou réduire la fenêtre |
| `Win + ←` | Ancrer la fenêtre à gauche |
| `Win + →` | Ancrer la fenêtre à droite |
| `Win + Home` | Réduire toutes les autres fenêtres |
| `Win + Shift + ←/→` | Déplacer la fenêtre vers un autre écran |

---

## Bureaux virtuels

| Raccourci | Action |
|-----------|---------|
| `Win + Tab` | Vue des tâches |
| `Win + Ctrl + D` | Nouveau bureau virtuel |
| `Win + Ctrl + ←` | Bureau précédent |
| `Win + Ctrl + →` | Bureau suivant |
| `Win + Ctrl + F4` | Fermer le bureau actuel |

## Capture d'écran

| Raccourci | Action |
|-----------|---------|
| `Win + Shift + S` | Outil Capture d'écran |
| `Win + PrtScn` | Capture de tout l'écran dans Images\Captures |
| `Win + Alt + PrtScn` | Capture de la fenêtre active (Game Bar) |

## Astuces à connaître ⭐

### Ouvrir rapidement un terminal administrateur
```text
Win + X puis A
```

### Ouvrir le Gestionnaire des tâches
```text
Ctrl + Shift + Esc
```

### Afficher le Bureau temporairement
```text
Win + ,
```

### Verrouiller immédiatement le PC
```text
Win + L
```

### Capturer une zone précise de l'écran
```text
Win + Shift + S
```
